# STEP Import для SketchUp (через FreeCAD)

*English version: [README.md](README.md)*

Расширение для SketchUp, которое импортирует **сборки STEP** с сохранением структуры:
детали становятся группами, повторяющиеся детали (винты, гайки…) — **компонентами**,
а тяжёлые узлы вроде платы с компонентами можно склеить в один меш.
Результат сохраняется рядом со STEP-файлом как `.skp`.

Ruby API SketchUp не умеет читать STEP (это B-Rep/NURBS-формат), поэтому геометрию
обрабатывает [FreeCAD](https://www.freecad.org/) в консольном режиме, а расширение
собирает модель в SketchUp.

## Возможности

- Иерархия сборки сохраняется в виде вложенных групп
- Одинаковые детали находятся автоматически → одно определение компонента, много экземпляров
- Крупные контейнеры (по умолчанию от 50 деталей) склеиваются в один меш: плата
  с ~1200 компонентами импортируется за секунды
- Копланарные треугольники из STL склеиваются в многоугольники (грани плоских поверхностей
  не разбиты на треугольники), отдельная очистка не нужна
- Мелкие грани не теряются: геометрия строится в 10 раз крупнее, а экземплярам задан
  обратный масштаб (`BUILD_SCALE`, см. [README.md](README.md))
- Собственное окно прогресса: этап, текущая деталь, журнал, время, кнопка **Отмена**
- Окно консоли FreeCAD скрыто
- Результат сохраняется как `<имя>.skp` рядом со STEP
- Окно **Настроек**: язык интерфейса (английский, русский) и путь к FreeCADCmd
- Журнал работы: `%TEMP%\step_import.log`

## Требования

- **Windows**
- **SketchUp 2021 или новее** (Ruby 2.7+); разработано и проверено на SketchUp 2024
- Установленный **FreeCAD** (`FreeCADCmd.exe`); отдельный Python не нужен

## Установка

1. Скачайте `eugenyh_step_import-<версия>.rbz` на странице [Releases](../../releases)
   (или соберите сами: `python build_rbz.py`).
2. SketchUp: **Window → Extension Manager → Install Extension**, выберите `.rbz`.
3. Перезапустите SketchUp.

При первом запуске расширение ищет `FreeCADCmd.exe` в обычных местах установки
(`Program Files` на любом диске, `%LOCALAPPDATA%\Programs`); если не нашло, спросит путь
и запомнит его. Изменить путь можно в любой момент в окне настроек.

## Использование

**Extensions → STEP Import (FreeCAD) → Импортировать сборку STEP…**, выберите `.step` / `.stp`
и следите за окном прогресса. Во время импорта модель лучше не редактировать: построение идёт
одной операцией, которая откатывается при отмене или ошибке.

> Интерфейс по умолчанию английский: пункты меню и окна переключаются на русский
> в настройках (см. ниже).

## Настройки

**Extensions → STEP Import (FreeCAD) → Settings…** (или «Настройки…», если выбран русский)

- **Язык** — язык интерфейса. Окна и сообщения переключаются сразу, названия пунктов меню
  обновятся после перезапуска SketchUp.
- **Путь к FreeCADCmd.exe** — введите вручную, нажмите **Обзор…** или **Найти автоматически**.
  Пустое поле означает автоматический поиск FreeCAD при следующем импорте.

Настройки хранятся в `%APPDATA%\EugenyH\StepImport\settings.json` (небольшой JSON-файл,
его можно править вручную):

```json
{
  "language": "ru",
  "freecadcmd": "D:/Program Files/FreeCAD 1.1/bin/FreeCADCmd.exe"
}
```

## Добавление языка

Весь текст интерфейса лежит в `src/eugenyh_step_import/locales/<код>.json`.

1. Скопируйте `en.json` в `<код>.json` (например, `de.json`).
2. Переведите значения; ключи и `%{подстановки}` не меняйте, в `"_language_name"` впишите
   название языка для окна настроек.
3. Запустите `python tools/check_locales.py` — он проверит, что ключи и подстановки совпадают с `en.json`.

Новый язык появится в окне настроек автоматически; недостающие ключи берутся из английского.
Журнал работы (`step_import.log`) всегда пишется на английском.

## Ограничения

- **Цвета и материалы не импортируются** (`FreeCADCmd` не читает цвета STEP, а STL их не хранит).
- Единицы считаются миллиметрами.
- Сборки из `App::Link` могут импортироваться не полностью.
- Если геометрия детали «запечена» в глобальные координаты, повторы не распознаются
  и остаются отдельными группами.
- SketchUp отбрасывает грани и рёбра ниже своего внутреннего допуска (около 0,001″ в
  координатах модели). Чтобы мелкие треугольники сохранялись, геометрия строится в
  `BUILD_SCALE` раз крупнее, а экземпляры масштабируются обратно, поэтому у них масштаб
  1/`BUILD_SCALE`; если такой экземпляр «взорвать» (Explode), геометрия уменьшится снова
  и мелкие грани могут пропасть. На тестовой плате по-прежнему теряется 468 из 161 523
  треугольников (0,3 %), без масштабирования терялось 34 528 (21 %).
- Интерфейс доступен на английском и русском; проверено только на Windows.

## Диагностика

Ход работы пишется в `%TEMP%\step_import.log` (читается во время импорта). При ошибках
временная папка `%TEMP%\step2stl…` сохраняется: там STL, `manifest.json`, `freecad.log`
и `error.txt`. Если FreeCAD не найден или перенесён — укажите путь в **Настройках**.
Подробности и заметки о производительности Ruby API SketchUp — в
[README.md](README.md).
